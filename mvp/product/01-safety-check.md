# 実験前の安全チェック

以下のどれか1つでも「いいえ」の場合、そのまま実験を開始しないでください。

| 確認 | はい/いいえ | 対応 |
|---|---|---|
| 入力から個人を特定できる情報を除ける |  | 仮名・架空データへ置換 |
| 契約、価格、顧客、未公開計画等の秘密を除ける |  | 公開情報または架空条件だけで試す |
| AIの出力を確認する担当者がいる |  | 最終確認者を決める |
| 間違っても直ちに顧客へ送信されない |  | 下書き専用の工程にする |
| 使用するAIサービスの社内利用が許可されている |  | 責任者へ確認する |
| 実験をいつでも停止できる |  | 自動送信・自動実行を使わない |

## 即時停止条件

- 実データを誤って入力した
- 顧客へ未確認の出力を送った
- 差別的、攻撃的、虚偽の内容が出力された
- 出力の根拠を確認できない
- 担当者が危険または不快と判断した

停止した場合は入力内容を再利用せず、責任者と利用サービスの案内に従ってください。
