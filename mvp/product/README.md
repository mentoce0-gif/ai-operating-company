# 1業務7日ラボ MVP v0.1.0

AIを導入するための商品ではありません。1つの業務を7日間だけ実験し、**続ける・直す・やめる**を数字で決めるための商品です。

## 7日後に残るもの

- 実験前後の作業時間
- 手戻り回数
- 人による品質評価
- 安全に運用できる条件
- 採用・改善・不採用のDecision Memo

成果が出なかった場合も、投資を見送る根拠が残れば実験成功です。

## 最初に読む順番

1. `01-safety-check.md`
2. `02-work-selection.md`
3. `protocols/` から対象業務を1つ選ぶ
4. `03-seven-day-log.md`
5. `04-decision-memo.md`

## 対応業務

- 問い合わせ返信の下書き
- 会議後の議事録・タスク整理
- 定型的な見積・提案文の下書き

対象外の業務へ転用せず、まず1つだけ完了してください。

## 守ること

- 個人情報、契約情報、営業秘密、未公開情報を生成AIへ入力しない
- AIの出力を人が確認する
- 医療、法務、採用、融資等の重大な判断をAIに行わせない
- 使用するAIサービスの利用条件とデータ取扱いを自社で確認する

本商品は法務・情報セキュリティ・業務品質を保証するものではありません。

## 更新

MVP購入者には購入日から90日間、PATCHおよびMINOR更新を無償提供します。変更理由は `CHANGELOG.md` に記録します。
