# AI Operating Company OS v0.1

AI社員が案件を企画・制作・販売・改善するための、ローカル完結型オペレーティングOSです。

## 起動方法

`index.html` をブラウザで開くだけで利用できます。外部ライブラリ、ビルド、サーバーは不要です。

GitHub Pagesでは、この `mvp/website` ディレクトリを公開対象にしてください。

## データ

- 編集内容はブラウザの `localStorage` に自動保存されます。
- 「JSONで保存」で全データを書き出せます。
- 「JSONを読込」で保存済みデータを復元できます。
- 最小スキーマは `sample-data.json` を参照してください。

## 拡張方針

`app.js` の `state` が単一のデータソースです。画面は `views`、追加フォームは `formConfigs` に登録する構成のため、新しい事業部属性、AI社員の能力、商品フェーズ、KPIなどを段階的に追加できます。
